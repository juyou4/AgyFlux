# Google 授权

## 添加账号

在「账号 → 添加账号 → Google 授权」中开始登录。默认打开浏览器。关闭自动打开选项后，可以复制链接到其他浏览器。

等待页显示授权链接、剩余时间和取消按钮。若回调未自动完成，展开「回调没有自动完成？」并粘贴该次登录的完整回调地址或授权码。授权过期或取消后，可以重新开始。

应用保存账号后会显示邮箱。可选择「再添加一个」或「完成」，额度会在后台更新。浏览器预览使用模拟账号。

## 配置 OAuth 客户端

从源码构建的程序需要具备相应权限的 Google 桌面 OAuth 客户端。启动程序前，在当前终端设置客户端。

```powershell
$env:ANTIGRAVITY_OAUTH_CLIENTS = 'desktop|<客户端 ID>|<客户端密钥>|Google Desktop'
```

也可以在本地构建配置 `.cargo/config.toml` 中设置以下变量。

```toml
[env]
AGYFLUX_GOOGLE_OAUTH_CLIENT_ID = "<客户端 ID>"
AGYFLUX_GOOGLE_OAUTH_CLIENT_SECRET = "<客户端密钥>"
```

已有刷新令牌与签发时的 OAuth 客户端关联。更换客户端后，请使用新客户端重新授权。

## 授权会话

自动回调和手动提交沿用同一授权会话。回调与会话的地址和状态匹配，并使用 S256 PKCE 校验。取消或过期的会话不能保存账号；授权链接、回调码和令牌不会保存在浏览器偏好中。
