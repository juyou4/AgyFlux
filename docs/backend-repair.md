# 后端架构与数据边界

## 账号状态与凭据

- 刷新账号时，后端重新读取当前状态并按字段合并。已删除或凭据已变更的账号不会被旧请求写回，较早的额度记录不会覆盖新的观测值。
- 账号列表和详情使用 `AccountView`，只返回界面所需信息。显式导出支持账号迁移，导出文件可能包含凭据。
- 账号凭据保存在本地账号 JSON 中，可用 `ABV_DATA_DIR` 指定数据目录。请妥善保管数据目录与导出文件。

## 客户端切换

- 各客户端分别展示已确认的运行会话、已保存凭据或无法确认的状态。
- 手动和自动切换共用客户端写入流程。按优先级调度时，较小的数字优先；同级账号按候选队列顺序处理。
- 写入失败会报告对应错误。设备标识数据库同步失败时会尝试恢复设备 JSON。跨文件、数据库和系统凭据库的写入不具备整体回滚保证。
- 原始设备指纹备份保存第一次采集的基线。

## 额度与预热

手动和批量预热遵循同一套冷却规则。仅对已知满额的模型预热，缺少账号项目或所有请求失败时会报告错误。
